# Vinkällaren

En fristående webbsida som visar vinkällarens innehåll: varje flaska som en cirkel i "hyllan", filtrering på vintyp, land och drickfönster, smakklockor och förslag på vin till middagen.

Öppna `index.html` direkt i webbläsaren, eller aktivera GitHub Pages för repot för att visa sidan på webben.

Knappen "Fråga Claude i stället" syns bara när sidan körs som Artifact på claude.ai; i övrigt används den inbyggda matchningen.
